# Pathology inference in Rust

Lymph-node metastasis detection on PatchCamelyon: a TensorFlow model exported to ONNX, served by a Rust service
with dynamic batching, and a plain-JavaScript viewer that draws tumour heatmaps.

Work in progress: built in sprints, see the [milestones](https://github.com/Tajaddin/pathology-inference-rs/milestones).
